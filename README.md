# PBS Motion Forecast

Heave, pitch and roll forecast for the drillship Petrobras 10000 from the DTN Marine Daily Planner, with best-heading scenarios and a helideck (NORMAM-27, AW139 / S-92) green/red probability. Static page, runs entirely in the browser.

Made by Toolpusher Gabriel Cunha. Model notes and validation (MRU blind test, and helideck vs HMS records 18 Sep – 18 Oct 2026): see `validation.html`.
